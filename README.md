# 🌌 Interactive 3D Galaxy Experience (Three.js)

## Overview

This project is an immersive 3D interactive galaxy built with Three.js and WebGL. It renders a dynamic spiral galaxy composed of animated text sprites, particle stars, a simulated black hole core, ambient glow effects, and interactive visual overlays.

The experience combines real-time 3D rendering, procedural texture generation, audio playback controls, mobile compatibility, and interactive particle effects — all inside a single-page web application.

## Key Features

- Real-time 3D galaxy rendered with Three.js
- Procedurally generated starfield textures
- Spiral galaxy with animated text sprites
- Black hole core with halo and photon ring effects
- Smooth orbit camera controls (zoom, rotate, damping)
- Responsive design for desktop and mobile
- Background music player with custom file upload support
- Double-tap / double-click heart particle effects
- WebGL compatibility detection and graceful error handling
- Layered UI overlays with glassmorphism styling

## Technical Highlights

- Three.js (WebGL rendering engine)
- Canvas-based dynamic texture generation
- Sprite-based text rendering in 3D space
- Custom particle system (hearts overlay)
- AudioContext API integration
- Performance optimization via buffer geometries
- Responsive camera reconfiguration
- Additive blending for glow and halo effects
- Separation of rendering layers (3D scene + 2D FX canvas)

## How to Run

1. Open the `.html` file in a modern browser (Chrome, Edge, Firefox).
2. Ensure WebGL is enabled.
3. Click to start the experience.
4. Optionally upload a custom MP3 file.

No build tools or installation required.
